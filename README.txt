디지몬 RE:서바이버 · 스컬그레이몬 E 화염폭발 패치

적용
- 기존 게임 폴더의 patch.js를 이 압축의 patch.js로 덮어씁니다. 기존 assets 폴더는 그대로 둡니다.
- GitHub Pages에서는 index.html의 patch.js 참조 뒤 버전 쿼리를 ?v=skull-fire-20261024로 바꾸고 강력 새로고침합니다. 쿼리가 없다면 추가합니다.
- 이 patch.js에는 이전까지의 패치가 누적되어 있습니다. 신규 이미지 파일은 없습니다.

변경
- 스컬그레이몬 E의 착탄 예고 뒤, 실제 타격 순간 밝은 화염 중심부, 확장되는 불꽃 고리와 도트 파편이 나타납니다. 판정, 피해, 발사 간격, 타격음은 유지합니다.
- 수동 E와 스컬그레이몬의 패시브 자동 포격에 스킬 지속시간 보너스를 각각 적용합니다. 기본 4초 × (1 + 지속시간 보너스)입니다. 보너스만큼 포격 횟수가 늘어납니다.
- 두 E 포격의 폭발 판정과 예고 원에 스킬범위 배율을 함께 적용합니다. 기본 반경 60 × 스킬범위 배율입니다.
- 궁극기 포격은 이번 E 전용 변경의 대상이 아닙니다.

검증
- JavaScript 구문 검사, 수동/패시브 지속시간 1.5배, 중복 보정 방지, 착탄 시 이펙트 생성 및 수명 종료, 기존 티라노몬/그로기 회귀 모의 검사 통과.
- 실제 브라우저 플레이의 시각·오디오 검증은 수행하지 못했습니다.
