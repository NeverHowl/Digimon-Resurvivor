디지몬 RE:서바이버 · 최종 보스 전뇌공간 필드 및 보상 순서 패치

적용
- 직전 스컬그레이몬 화염폭발 패치에 이어 적용합니다.
- 압축의 patch.js를 게임 폴더에 덮어쓰고, assets/maps/ 아래 신규 PNG 8개를 같은 경로에 추가합니다. 나머지 기존 리소스는 그대로 사용합니다.
- GitHub Pages의 index.html에서 patch.js 쿼리를 ?v=cyber-stages-1로 변경하고 새 파일까지 업로드한 뒤 강력 새로고침합니다. 경로 및 파일명 소문자를 유지합니다.

변경
- 아포카리몬 등장부터 보스전 종료까지 어두운 보라색 전뇌공간 타일을 사용합니다.
- 이그드라실 등장부터 보스전 종료까지 밝은 은백색 전뇌공간 타일을 사용합니다. 엔딩의 흰 공간은 기존 연출을 유지합니다.
- 보스별 타일 4종을 생성하며, 모든 변형의 가장자리 픽셀이 일치하여 맵에서 이음새 없이 반복됩니다.
- 케루비몬 격파 후 레벨업·보스 보상 등 대기한 선택을 모두 끝낼 때까지 아포카리몬 등장과 대사를 보류합니다. 선택이 끝나면 짧은 노이즈 전환 후 등장·대사가 시작됩니다.
- 체험하기의 격자형 배경은 유지합니다.

검증
- JavaScript 구문 검사, 신규 PNG 8개 디코딩, 768×768 규격과 타일 경계 검사, ZIP 무결성 검사.
- 여러 보상이 연속되는 전환 및 두 보스의 타일 경로를 모의 실행하여 확인했습니다.
- 실제 브라우저 게임 플레이에서의 시각·오디오 테스트는 수행하지 못했습니다.
