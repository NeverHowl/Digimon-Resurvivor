설치: 직전 '케라몬 계통 테스트'가 적용된 게임 폴더에서 index.html과 patch.js를 교체하세요. 이전에 추가한 assets는 그대로 둡니다. GitHub Pages도 두 파일을 같은 경로에 올리세요.

- 분신 근접 평타와 자폭 모두 물리 스택을 쌓지 않습니다.
- 분신 평타는 평타 타격음만 사용합니다. 공용 피해 함수가 함께 출력하던 스킬 타격음을 제거했습니다.
- 디아블로몬 분신의 평타 적중 및 자폭 후 새 분신 생성 확률을 각각 10%에서 5%로 낮췄습니다. 자폭 확률은 타격 대상별이 아니라 폭발당 한 번만 판정합니다.
- 주변에 다른 적이 있다면 분신은 서로 다른 적을 우선 지정합니다. 분신이 적보다 많으면 적별 분신 수를 고르게 배분합니다.
- 소환 위치를 분산하고, 이동 중 분신 간 최소 간격을 유지해 도트가 서로 겹치지 않도록 했습니다.

검증: JavaScript 문법, 네 단계의 E/Q·분신 타격, 물리 스택 0, 평타음 한 번/스킬음 0회, 다른 적 우선 지정, 소환 시 간격, 적의 분신 피격을 스모크 테스트로 확인했습니다. 브라우저의 실제 전투 화면은 이 환경에서 확인하지 못했습니다.
