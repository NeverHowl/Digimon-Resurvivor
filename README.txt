디지몬 RE:서바이버 — 서브웨폰 입력 수정 패치

직전 메기드라몬 자동 검기 수정 버전에 이 ZIP의 patch.js를 덮어쓰세요. 기존 index.html과 assets는 그대로 사용합니다.

- 구버전 서브웨폰 6종의 커서 방향 발사·설치가 적 탐색 조건에 막히던 문제 수정
- 프로스트 노바는 주변에 적이 없어도 즉시 발동
- 화염탄과 블레이드 웨이브 첫 발이 키 입력 즉시 생성
- 체인 스파크는 커서 주변에 적이 없을 때 소유자 사거리 800 안의 가장 가까운 적을 탐색. 실제로 적이 없으면 안내 문구를 띄우고 쿨다운을 쓰지 않음
- 숫자패드 1~3 입력 지원

검증: JS 문법 검사, 18종 서브웨폰 무대상 발동 경로 및 커서 밖 연쇄 전격 모의 실행 통과. 전투 중 특정 상태(진화 연출, 궁극기 연출, 메기드라몬 폭주)에서는 기존 입력 제한을 유지합니다. 브라우저 실화면 플레이 검증은 수행하지 못했습니다.
