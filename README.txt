적용: 기존 게임 폴더 또는 GitHub 저장소의 patch.js를 덮어씁니다.
index.html, retro_ui.js, retro_ui.css, assets는 기존 파일을 유지합니다.
GitHub Pages 배포 뒤 강력 새로고침(Ctrl+F5)으로 갱신하세요.

변경
- 보스 원형 장판의 중복 채우기, 보스 탄막과 일반 투사체의 다중 필터, 넓은 필드 배경 그리기, 매 프레임 HUD 재구성을 줄였습니다.
- 경험치 보석을 위치별로 관리하여 근처 흡수와 화면 표시 때 먼 곳의 보석을 전부 검사하지 않습니다. 합쳐진 보석의 경험치 총량과 흡수 조건은 유지합니다.
- 브레스 시각 파티클의 개수 검사를 한 프레임에 한 번 공유하고, 동시에 쌓이는 순수 시각 효과의 상한을 조절했습니다. 공격 판정과 속성 반응은 그대로입니다.
- 아포카리몬의 반복 소환으로 필드의 일반 적이 무한히 증가하지 않도록 생존 소환몹을 32마리까지 제한했습니다.
- 화면 밖에서 시작해 화면 안으로 뻗는 긴 경고선 및 경고 중인 적은 그리기 생략 대상에서 제외했습니다. 보스 경고의 표시 시간과 타격 시간은 동일 패턴에 묶여 있습니다.
- F8 성능 표시: FPS, 객체 수, 경험치 보석 수, 전투 계산(U)과 그리기(D) 평균 ms, 현재 보스 패턴을 확인할 수 있습니다.

확인: JavaScript 구문 검사와 모의 전투 테스트를 통과했습니다. 2,000개 보석의 근접 조회, 경험치 보존, 경고 장판 지속, 화면 밖 경고선, 아포카리몬 소환 상한, 케라몬 전투 기능을 검사했습니다.
실제 브라우저 프레임 시간과 시각적 가독성은 플레이 환경에서 F8로 확인해야 합니다.
