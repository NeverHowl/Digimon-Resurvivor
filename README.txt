적용: 기존 게임 폴더의 patch.js를 이 압축파일의 patch.js로 덮어쓰세요. 기존 index.html과 assets 폴더는 유지하세요. 이전 추추몬 평타 PNG 두 장이 계속 필요합니다. GitHub에 올릴 때 경로와 대소문자를 그대로 유지하세요.

이전 테스트 패치 포함
- 진화포인트·골드·속성 투자·특화 등 등급별 수치 보상에는 실제 선택된 등급의 수치만 표시.
- 이미지 투사체의 픽셀 윤곽선 캐시, 코드 도형 탄의 형태별 윤곽선. 무거운 투사체 Canvas drop-shadow 필터와 판정 반경 타원선 제거.
- 투사체가 많을 때 브이몬·추추몬 탄의 장식 잔상 생성량 감소.

이번 추가 성능 패치
- 투사체가 32발 이상, 적이 16마리 이상일 때 적의 전체 피격 범위로 공간 격자를 만들어 투사체가 지나간 셀의 적만 충돌 후보로 조사. 후보는 기존 적 배열 순서대로 검사하며 보스의 큰 반경을 포함합니다.
- 첫 명중 후 격자를 다시 만들고, 한 프레임에 명중이 계속되면 전체 순회로 전환합니다. 관통탄은 첫 명중 이후 원래 순서대로 나머지 적을 검사합니다. 폭발의 주변 피해 검사와 실제 피격 판정은 유지합니다.
- 같은 장소에 연속으로 발생하는 브이몬 계통 및 추추몬 계통 투사체 타격 장식은 합쳐 그립니다. 명중·속성·피해·타격음은 각각 그대로 처리합니다. 장식 이펙트 예산에는 이들의 타격 잔상도 포함합니다.

검증: JS 문법 검사, 보상·외곽선 검사, 100발·적 32마리의 명중/미접촉 비교, 유도·관통·폭발·보스 피격 범위 비교. 미접촉 상황 피격 반경 확인 25,600회→256회, 동일 지점 80발 동시 명중의 타격 장식 80개→1개. 실제 Edge/Chrome의 FPS는 아직 브라우저에서 검증하지 않았습니다. 게임 내 F8 성능 표시로 U/D 시간을 비교하세요.
