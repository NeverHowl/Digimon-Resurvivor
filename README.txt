디지몬 RE:서바이버 · 아구몬 정규루트 스킬 이펙트 테스트 빌드

GitHub Pages 배포: ZIP 안의 파일과 assets 폴더를 저장소 최상위에 덮어씁니다. 기존 assets의 다른 파일은 삭제하지 않습니다. 업로드가 완료되면 강력 새로고침합니다.

도감 → 체험하기에서 아구몬/그레이몬/메탈그레이몬/워그레이몬을 선택하고 E와 Q를 사용해 확인할 수 있습니다.

- 아구몬: 앞선 테스트의 화염탄/폭발 스프라이트와 2배 표시 크기 유지.
- 그레이몬 E: 대형 화염탄과 명중 폭발. Q: 화염방사 3타(타격당 화염 1스택) → 뿔 돌진 → 원형 물리 충격파. 기존 컷인 유지.
- 메탈그레이몬 E/Q: 검은 미사일과 명중 폭발. Q의 마지막 전방 화염 분출에 전용 도트 적용. 기존 미사일 순차 발사 유지.
- 워그레이몬 E/Q: 거대한 화염구와 폭발. E의 시전 순간과 Q의 발사 전 충전 이미지 적용. 기존 궁극기 피해/컷인 유지.
- 제공 리소스의 실제 프레임 수를 사용: 그레이몬 화염방사/충격파는 각각 5프레임. 누락된 6프레임 파일을 요구하지 않습니다.
- 사용자 PNG는 각각 원래 파일명 그대로 포함하고 표시 단계에서만 확대합니다. 이미지 리소스는 게임 코드에도 포함돼 파일명 대소문자로 인한 GitHub Pages 누락을 막습니다.
