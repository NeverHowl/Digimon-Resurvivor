적용: 기존 게임 폴더 또는 GitHub 저장소의 patch.js를 덮어씁니다.
압축 안의 assets/effects/boss 폴더도 같은 경로로 복사합니다.
index.html, retro_ui.js, retro_ui.css와 다른 assets는 기존 파일을 유지합니다.
GitHub Pages 배포 뒤 강력 새로고침(Ctrl+F5)으로 갱신하세요.

변경
- 주작몬의 방사형·나선 탄막에 전용 불꽃 깃털 PNG를 발사 방향에 맞춰 출력합니다.
- 묘티스몬의 방사형 탄막에 전용 박쥐 PNG를 발사 방향에 맞춰 출력합니다.
- 이그드라실의 직선·십자·격자 타격에 전용 회로 빔 PNG를 길이 방향으로 이어 그립니다.
- 이미지 로딩에 실패하면 기존 코드 이펙트를 사용합니다.
- 보스 7종과 엘리트 12종의 경고 장판, 타격 순간, 탄막에 각자의 색과 픽셀 문양을 추가했습니다.
- 몬자에몬: 봉합선 / 묘티스몬: 박쥐 / 키메라몬: 혼합 뿔 / 주작몬: 화염 깃털 / 케루비몬: 광륜 / 아포카리몬: 글리치 / 이그드라실: 회로
- 엘리트는 스카몬, 팬텀몬, 데비드라몬, 쿰비라몬, 그로트몬, 아르보르몬, 라나몬, 메르큐레몬, 기가스몬, 페탈드라몬, 카라마라몬, 세피로트몬에 고유 문양을 적용했습니다.
- 기존 붉은 경고 표시와 진행 표시를 유지했습니다. 공격 판정, 범위, 피해량, 경고 시간은 변경하지 않았습니다.
- 직전 전투 성능 테스트 b의 보석 위치 조회, 경고선 표시 보정, 보스 전투 렌더링 경량화도 포함합니다.

확인: JavaScript 구문 검사, PNG 투명도·경로 검사, 기존 전투 모의 테스트, 성능 모의 테스트, 보스·엘리트 경고 이펙트 렌더링 모의 테스트를 통과했습니다.
실제 브라우저에서 각 보스와 엘리트의 전체 패턴 플레이 검사는 아직 수행하지 못했습니다.
