GitHub Pages: ZIP 안의 파일과 assets 폴더를 저장소 최상위에 덮어씁니다. 기존 assets의 다른 파일은 삭제하지 않습니다. 배포 후 강력 새로고침하세요.

도감 → 체험하기에서 팔몬/니드몬/릴리몬/로제몬의 E와 Q를 확인할 수 있습니다.

- 팔몬 E 씨앗: 3프레임. 니드몬 E/Q 가시: 제공된 단일 프레임을 반복 사용합니다.
- 릴리몬 E와 Q의 유도탄: 3프레임 꽃탄을 사용합니다.
- 로제몬 E: 3프레임 가시 채찍을 기존 전방 범위에 맞춰 사용합니다.
- 팔몬·로제몬 Q 장판: 6프레임 덩굴 정원을 반복 표시합니다. 초록색 반투명 원과 자라나는 씨앗 이미지입니다.
- 릴리몬 Q의 마지막 범위 폭발과 로제몬 Q의 대상별 꽃 폭발: 공용 꽃잎 폭발 5프레임.
- 포자 표식 부여·폭발: 공용 포자 폭발 4프레임. 기존 포자 추가 피해, 스택, 장판 지속시간은 그대로입니다.
- 앞선 아구몬·파피몬 계통 이펙트, 메탈가루몬 근접평타 및 고드름 방향 수정도 포함합니다.
- 사용자 PNG는 각각 원래 파일명을 유지하며 코드에도 프레임을 내장해 GitHub Pages의 파일명 대소문자 문제를 피합니다.
