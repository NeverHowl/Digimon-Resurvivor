적용: 기존 게임 폴더의 patch.js를 이 압축파일의 patch.js로 덮어쓰세요. 기존 index.html과 assets 폴더는 그대로 사용하세요. GitHub 배포에서는 파일 경로와 대소문자를 유지하세요.

추가 수정
- 치명타 확률 보상 카드에 선택된 등급의 실제 증가량만 표시: 일반 +5%p, 희귀 +8%p, 영웅 +12%p, 전설 +18%p. 평타·스킬 모두 적용되며 100% 초과 시 강화 치명타 안내는 유지합니다.
- 상점 보상 설명이 다른 칸에 표시될 수 있는 칸 순서를 수정했습니다.

이전 테스트 포함
- 진화포인트, 골드, 속성 투자, 특화 등 등급별 보상에 선택된 등급의 수치만 표시.
- 이미지 탄 픽셀 윤곽선 캐시, 코드 탄 형태별 윤곽선, 무거운 그림자 필터와 판정 반경 타원선 제거.
- 브이몬·추추몬 투사체 장식 잔상을 줄이고, 겹친 장식 타격 효과를 합쳐 그립니다.
- 투사체 32발, 적 16마리 이상에서 공간 격자를 이용해 충돌 후보를 추립니다. 충돌 범위, 피해, 타격음과 보스 경고 판정은 유지합니다.

검증: JavaScript 문법 검사 및 네 등급의 카드 설명과 실제 증가량 비교 통과. 실제 브라우저 FPS는 별도로 측정하지 않았습니다. F8 성능 표시의 U/D 시간을 확인할 수 있습니다.
