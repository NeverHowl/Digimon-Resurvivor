이번 개편

- 불씨의 지속시간 7초, 생성·중첩·반응 규칙, 스킬 피격 반경은 변경하지 않았습니다.

기존 누적 패치: 선택된 등급의 보상 수치 표시(치명타 확률 일반 5/희귀 8/영웅 12/전설 18%p 포함)와 투사체 성능 개선이 들어 있습니다.

이미지 제작: 기본 이미지 생성 기능으로 투명한 8종 도트 불씨를 만들고, 각 속성을 분리해 최근접 픽셀 방식으로 64×64 PNG에 정리했습니다. 작은 화염, 얼음 결정, 씨앗 잎, 번개, 바람 소용돌이, 바위, 빛 별, 어둠 초승달을 사용했습니다.

검증: JavaScript 문법, 8개 PNG의 투명도·크기·경로, 표시 함수의 이미지 호출·미로드 대체도형·수명 종료 위임 검사 통과. 실제 게임 브라우저 출력은 이 테스트 빌드에서 확인해 주세요.
