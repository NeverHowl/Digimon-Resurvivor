# v0.18.24 — 증강 시스템 인프라 (2단계)

일반 플레이에는 **아직 증강을 얻는 경로가 없습니다**(보상·상점 연동은 다음 단계). 체험장에서만 부여해 확인할 수 있습니다. 증강이 없는 개체의 전투 동작은 v0.18.23a와 동일합니다(242종 전수 비교 차이 0).

## 확정한 정책 (추천안)
| 항목 | 정책 |
|---|---|
| 소유 | **개체 귀속** (`c.aug = {증강ID: 레벨}`) — 같은 종을 여러 마리 키워도 서로 섞이지 않음 |
| 진화·퇴화 | 같은 개체 객체이므로 그대로 유지 |
| 판매·교체·제거 | 개체와 함께 **소멸** (유물 보관함과 달리 보관 없음) |
| 조그레스(융합) | 피제물의 증강 **레벨을 합산**해 받는 개체에 이전 |
| 기적 부활 | **복사**(`V181_GROWTH` 복원 경로) |
| 런 종료/새 런 | 초기화. 다회차 메모리 저장소와는 무관 |
| 중복 획득 | 레벨 상승, **상한 없음**. 수치는 선형 구간(기본 5레벨) 이후 완만한 점감 곡선 |

## 만든 것
- **데이터/API**: `AUG_DEFS`, `augLv/augAdd/augList/augClear`, `AUG_CHANGED` 이벤트.
- **보호 계층 등록**: `V181_GROWTH`·`V181_PROTECTED`(부활·복원·무단 변경 되돌림), `DS_LABEL`(진단 라벨), `rhBuild`(런 기록에 증강 목록), 획득 시 런 이벤트 기록.
- **안전 한도**: 프레임당 파생 피해 예산 24(`augBudget`), 같은 대상·같은 증강 내부 재발동 시간(`augGate`), 증강 피해 재귀 차단(출처 `aug` 피해는 증강 트리거를 일으키지 않음, 깊이 2 제한), 피해량 보정은 최외곽 1곳(`AUG_HITMODS`, 중첩 호출 이중 적용 방지).
- **TAG_IN 이벤트**: 활성 개체가 바뀔 때 1회 발생. 일반 교대·강제 태그(레드 카드 등)·자동 교체를 모두 감지.
- **UI**: 상태창에 증강 이름·레벨·효과 표시 / 체험장 보상 패널에 "증강 (체험)" 분류(+1, +5, 초기화) / 한·영 번역.

## 시험용 증강 2종 (⚠ 수치는 모두 임시·미승인)
수치는 `AUG_TUNE` 한 곳에서만 바꿉니다.
- **#10 최후의 일격**: 체력 30% 이하 적에게 주는 피해 +20%(레벨당 +10%, 5레벨 이후 +4%/레벨), 엘리트·보스는 효과 절반. 직접 피해(평타/E/Q/서브)에만 적용, 증강 파생 피해는 제외. (실측: Lv1 ×1.20 · Lv5 ×1.60 · Lv8 ×1.72 · 체력 높은 적 ×1.00 · 엘리트 ×1.10)
- **#13 교대 강습**: 태그로 등장하면 주변 반경 140(+12/레벨)에 공격력의 80%(+40%/레벨, 5레벨 이후 +15%)의 충격파, 재발동 1초, 한 번에 최대 16체. 

## 검증
- 피해 보정 정확도/중첩 이중 적용 없음/파생 피해 제외/엘리트 절반 확인.
- 교대 강습: 일반 교대·강제 태그 모두 발동, 재발동 대기, 범위 밖 미적용, 60체 중 16체 상한.
- 조그레스 합산, 기적 부활 복원(스냅샷→복원), 진화 유지, 보호 구간에서 무단 변경 되돌림, 새 런 초기화, 런 기록 반영.
- 체험장: 목록/+1/+5/초기화/버튼 클릭, 체험 초기화 시 증강 소멸, 다른 분류(유물) 영향 없음, 영문 표시 확인.
- E 사용 감지 242종 전수 실패 0 / 242종 쿨다운·투사체 수 v0.18.23a와 동일 / 히트 처리 시간 차이 없음.

## 알려진 한계
- 증강을 얻는 경로 없음(보상·상점·보스 보상은 3단계).
- 이름 "최후의 일격/교대 강습"의 영문명(Final Blow / Tag Assault)은 임시입니다.
- 교대 강습의 충격파는 피해 판정만 있고 전용 이펙트는 기존 링 효과를 재사용합니다.
- 자동 교체(전투불능 시)도 "태그 등장"으로 취급됩니다.
- 비활성 개체의 증강은 현재 시험용 2종 모두 "활성일 때만" 의미가 있어 별도 휴면 처리가 없습니다(다음 증강 추가 시 정책 필요).
