# v0.18.25a — 증강을 종류별 보상 카드로

## 덮어쓸 파일
`index.html`, `patch.js`, `lang_en.js` (lang.js 변경 없음)

## 변경
- "증강 선택" 칸과 3지선다 단계를 제거. **증강 1종 = 보상 카드 1장**으로 직접 등장하고, 누르면 바로 대상 파티원 선택.
- 증강 이벤트가 나면 **서로 다른 증강 1~3종**이 한 번에 등장 (장수 확률 `counts`).
- 레벨업 창: 앞 2장(보장 카드)·유물·서브웨폰 칸은 보호, 그 뒤 카드를 증강 카드로 교체. 교체할 카드가 없으면 추가(전체 버튼 6장 상한). 리롤·돌아가기 후에도 유지.
- 엘리트/보스 창: 기존 선택지는 그대로 두고 증강 카드를 추가.
- 체험장: "증강 선택창 열기" 버튼 삭제, "증강 100% 강제" 시 최대 장수로 등장. 확률 표시 문구 갱신.
- 카드에 파티 보유 현황 표시, 영어 번역 갱신.

## 임시 수치 (미승인, `AUG_TUNE.reward`)
이벤트 확률 레벨업 6% / 엘리트 15% / 보스 25%, 장수 1·2·3장 = 70/25/5%, 레벨업 창 버튼 상한 6.
(현재 증강 2종이라 3장은 2장으로 제한됨)
