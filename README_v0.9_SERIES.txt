디지몬 서바이버 v0.9 SERIES

[v0.9.0] ELEMENT EXPANSION
- 신규 속성: 바람 / 땅 / 빛 / 어둠
- 신규 상태: 휘청임 / 진동 / 실명 / 저주
- 신규 반응 순서(방향 고정):
  1. 바람 → 화염 = 화염폭풍
  2. 바람 → 냉기 = 빙풍
  3. 땅 → 바람 = 모래폭풍
  4. 빙결 → 땅 = 쇄빙
  5. 전기 → 땅 = 접지
  6. 빛 → 전기 = 섬광
  7. 빛 ↔ 어둠 = 혼돈
- 반응 피해는 신규 속성 스택/추가 반응/진동 재전이를 발생시키지 않음
- 진동: 스택당 20% 피해전이, 5스택 100%, 재전이 차단
- 휘청임: 피격 시 0.1~0.5초 스턴, 보스 효율 감소 및 내부 쿨다운 적용
- 실명: 적이 주는 피해 감소, 5스택 -90%의 짧은 억제시간
- 저주: 적이 받는 피해 +10~30%, 적이 주는 피해 +6~20%
- 신규 속성 강화 카드 4종, 신규 서브웨폰 8종, 신규 속성개조 4종
- 파타몬/플롯몬 Light, 호크몬 Wind, 아르마몬 Earth, 악마/임프몬 계통 Dark 중심 개편
- 피요몬은 Fire 스택 유지 + E에 Wind 피해계수 추가
- 페가수스몬은 Wind 스택만 부여
- 엑스브이몬 정규계 Light 계수 + E 실명 추가
- 크레스가루몬, 쉬라몬 계통, 브이드라몬 계통, 샤크라몬, 테리어몬은 요청대로 기존 속성 정체성 유지
- 신규 지속 VFX는 Canvas filter 없이 단순 도형 기반으로 구현
- 신규 스킬/서브웨폰/반응 타격음 연결
