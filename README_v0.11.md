# 디지몬 서바이버 v0.11

`index.html`을 브라우저에서 열어 실행합니다. 자동 평타는 커서 방향, 좌클릭은 E, 우클릭은 대쉬, Q는 궁극기, Space/C는 태그, Z는 진화입니다.

이번 버전은 계통별 패시브와 진화 위협 체력 보정을 적용했습니다. 파티 상태(ESC)에서 보상으로 직접 선택한 특화 점수와 패시브 무료 메리트 점수를 확인할 수 있습니다. 화면 상단의 **진화 위협**은 일반몹 기준 체력 증가율입니다. 엘리트는 이 수치의 75%, 보스는 60%가 적용됩니다.

전체 변경 요약은 `PATCH_NOTES_v0.11.md`에 있습니다. 이전 버전의 상세 이력은 `PATCH_NOTES_v0.10.md`와 시리즈별 README를 참고하세요.
