## 바뀐 것
1. **보상 화면 "다른 보상 선택 / 돌아가기" 안전화.** 이 버튼은 전역에 저장된 "보상 화면 그리기 함수"를 클릭 순간에 불러 쓰고 있어서, 그 사이 다른 보상 화면이 함수를 바꾸거나 이미 끝난 보상이면 끝난 보상 목록을 다시 띄울 수 있었습니다. 이제 버튼이 적용 대상 화면이 열릴 때의 보상 화면에 묶이고, 그 화면이 끝났거나 바뀌었으면 누를 수 없습니다("이미 끝난 보상 화면입니다" 표시, 기록에 `back-blocked` 남김). 적용 대상 화면 4종(일반, 특화, 속성 강화, 진화 에너지)에 모두 적용했습니다.
2. **보상이 끝나면 되돌아가기 함수도 비웁니다.** 창이 닫힐 때마다 비우므로 다음 보상 화면이 이전 것을 물려받지 않습니다.
3. **창 겹침 방지.** 이미 창이 열려 있는데 대기 중인 보상/알 창이 또 열려 위에 덮어쓰는 일을 막습니다. 대기 중인 창은 현재 창을 닫을 때 이어서 열립니다. 막은 경우 기록에 `overlap`이 남아서, 실제로 그런 일이 있었는지 확인할 수 있습니다.
4. **기적: 사용하기 전에는 다시 나오지 않습니다.** 기적을 가진 동안은 레벨업 보상, 상점, 보스 보상 어디서도 기적이 후보에 들지 않습니다. 이미 만들어져 있던 목록에서 기적을 고르면 다른 유물로 바뀝니다. 기적을 쓰고 나면 다시 나올 수 있습니다.
5. 바이러스/백신/데이터 카드의 EVO +20은 의도된 동작으로 확인되어 그대로 둡니다.

## 확인한 범위 (Chromium, 자동)
- 되돌아가기: 일반/특화/진화 에너지 대상 화면에서 정상 클릭 시 같은 보상 목록으로 돌아감(목록 동일 확인). 화면이 바뀐 상태에서 누르면 거부되고 보상은 다시 열리지 않음. 창이 닫히면 함수가 비워짐.
- 창 겹침: 열린 창 위에 두 번째 보상이 덮어쓰지 않고, 닫은 뒤 이어서 열림.
- 기적: 보유 중 3,000회 뽑기에서 0회, 사용 후에는 다시 후보에 들어옴. 만들어져 있던 기적 제안은 다른 유물로 교체.
- 회귀: 진화 경로 해시 동일, 복구 8종, 기록 R1~R7, 시나리오 12개 결과가 v0.18.6과 완전히 같음, 치명 퇴화·전투불능·기적 부활 시험, 데이터 카드 오경보 0, 85초·60초 플레이 오류·경보 0.
- 확인하지 못한 것: 실제 Edge, 모바일 기기, 장시간 플레이.
