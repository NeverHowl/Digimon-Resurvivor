# v0.18.23 — E 사용 신호 · 피해 출처 정비 (증강 시스템 준비 1단계)

증강 효과/UI/보상/저장 데이터는 **추가하지 않았습니다.** 이후 증강·유물이 같은 규칙으로 "E를 썼다"와 "이 피해/처치는 어디서 왔다"를 읽도록 만든 내부 공통 층입니다. 화면 변화는 없습니다(버전 표기만 변경).

## 1. E 사용 규칙 (모든 스킬 공통)
| 종류 | 신호가 나가는 시점 | 해당 형태 |
|---|---|---|
| 즉발 | 시전 순간 | 대부분(215종 + 충전식 4종은 충전 소모마다 1회) |
| 홀드(차지·가드) | **발사(해제) 순간** (누르는 순간은 아님) | 세이버사그몬 계열 4, 류우다몬 계열 4, 코만드라몬·실즈드라몬·탱크드라몬·다크드라몬 (12종) |
| 모드·재시전형 | **최초 시전 1회.** 재시전·종료 입력은 같은 사용의 연장 | 가이오몬(2초 재시전), 오메가몬(2타), 브리가드라몬(폭파), 베지몬·블로서몬(덩굴 종료), 가오몬 계열 5(복싱 모드) 등 11종 |
- 구현: 파일 끝(최외곽)에 `AUG` 모듈 — `skillE` 래퍼 1개 + 해제 지점(`v092FireCharge`, `g27GuardDash`, `g27FireCharge`) 훅 + `E_USED` 이벤트(`augOn('E_USED',fn)`). 신호 payload: `{c, form, kind('instant'|'release'|'mode'), castId, cdBefore, cdAfter, cdRose}`.
- 기존 `R173_skill`(상태 비교 추측)은 제거했고, 융합세포는 `E_USED`를 구독합니다. 헤비 메탈의 쿨다운 +50%는 "쿨다운이 새로 시작되는 모든 E 호출"에 적용하는 별도 규칙(`augCdPenalty`)으로 분리했습니다.

## 2. 기존 동작이 바뀌는 점 (버그 수정 = 규칙 통일)
1. **융합세포**: 지금까지 발동하지 않던 형태에서 발동합니다 — G27 12종 전부, 모드형(가이오몬·오메가몬·덩굴 2종·가오몬 계열), 브리가드라몬 등. 242종 전부 감지 확인.
2. **헤비 메탈(쿨다운 +50%)**: 지금까지 누락되던 **34종**에서도 적용됩니다 — G27 11종(류우다몬 계열·코만드라몬 계열·하이코만드라몬·카르고드라몬·브리가드라몬), G15/G17/G18/G19/G20/V180 계열 23종(고블리몬 계열, 플로라몬 계열, 가지몬 계열, 델타몬 계열, 기자몬 계열, 사이클로몬 계열 등).
3. **홀드형 융합세포**: 누르는 순간 → 해제(발사) 순간으로 이동(세이버사그몬 계열 4종). 헤비 메탈은 기존에도 해제 시점이라 변화 없음.
4. 모드형 재시전은 "새 사용"이 아니므로 융합세포가 재발동하지 않습니다(예: 오메가몬 2타는 융합세포 비발동, 헤비 메탈 쿨다운은 종전처럼 적용).
※ 이 외 데미지·쿨다운·범위·연출 수치는 변경 없음(242형태 전수 비교: 쿨다운·투사체 수 동일, 차이는 헤비 메탈 34종뿐).

## 3. 피해 출처 태그 (1단계: 미분류 허용)
- `augOrigin(source,enemy)` → `'E' | 'basic' | 'Q' | 'sub' | 'aug' | 'unknown'`. `hitEnemy` 최외곽 래퍼가 `enemy.augLastHit`에 기록, `killEnemy` 래퍼가 `KILL` 이벤트 `{e,c,origin}`를 보냄(0.6초 이내 마지막 피해 기준). 태그가 없으면 `unknown`이며 **기존 동작은 바꾸지 않음**.
- 증강용 파생 피해 문맥 `augDerived(c,augId,fn)`: 출처 `'aug'`, 중첩 깊이 2 초과 시 실행하지 않음(재귀 차단 기본 규칙).
- 기존 공격 컨텍스트(v104 토큰·g17·v091)를 재사용하고, 한 번의 E 호출이 만드는 여러 토큰을 모두 E로 인정합니다.
- 서브웨폰: 즉시 발사 구간 + 발사체 표식. 설치형(지뢰·장판) 피해는 `unknown`.
### 현재 커버리지 (전수 하네스: 각 형태 E 1회 + 6초)
- 피해가 관측된 179종 중 **123종은 E 피해 100% 태그**, 4종 부분, **52종은 `unknown`**(지연·틱·소환체 경로가 아직 토큰을 잇지 않음), 63종은 하네스에서 피해 없음(보호막·버프·가드형 등).
- `unknown` 52종 (다음 단계 대상): 스컬그레이몬, 베지몬·블로서몬, 로토스몬, 마그나몬, 주얼비몬·반쵸스팅몬, 슈리몬, 라라몬·선플로몬·릴라몬, 카메몬·와파몬·샤우진몬·점보가메몬, 메기드라몬, 골드라피드몬, 미타마몬, 캔들몬, 반쵸레오몬, 시드라몬 3종, 메가드라몬, 아주롱몬, 피코데빌몬, 묘티스몬·베놈묘티스몬, 곳츠몬·골레몬·고그마몬·반쵸골레몬, 아이스몬·인섹키몬, 하구루몬·가드로몬·안드로몬·하이안드로몬, 고블리몬 계열 4, 디지타마몬·데비타마몬, 플로라몬 계열 4, 걸프몬, 하이코만드라몬·카르고드라몬·브리가드라몬.
- 이 형태들을 `E`로 인식시키려면 형태군별(덩굴/소환/쉘/꽃/석상 등) 틱 경로에 토큰 연결이 필요합니다(별도 승인 후 진행).

## 4. 검증
- E 사용 감지 전수(242종): 첫 사용 정확히 1회 / 홀드 12종 누름 0회·해제 1회 / 모드형 재입력 0회 / 충전식 4종은 2회째 사용 1회 → **실패 0**.
