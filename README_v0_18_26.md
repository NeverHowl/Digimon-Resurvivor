## 규칙
- "스킬" = E만 (Q는 출처 태그가 불완전하여 제외).
- 폭발 펀치의 폭발은 스킬이 아니므로 타격 마법을 일으키지 않음. 타격 마법의 추가타는 평타 판정이라 폭발 펀치를 일으킴(연쇄 최대 2단계).
- 파생 평타 타격도 여세의 타격·기존 평타 효과(유물)에는 반응. 증강 피해('aug' 출처)는 어떤 증강도 일으키지 않으며, **궁극기 게이지를 채우지 않음**(교대 강습 포함, 기존 동작 변경).
- 증강 타이머(폭탄·회복·피해감소·회피 창)는 일시정지 중에는 흐르지 않음.
- 증강 풀이 10종이 되어 보상 한 번에 최대 3장까지 등장 가능.
