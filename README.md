# 디지몬 RE:서바이버 v.0.14

## 실행 및 GitHub Pages 업데이트

전체판 ZIP의 **내용물**인 `index.html`, `patch.js`, `assets/`를 한 폴더에 풀고 `index.html`을 엽니다. GitHub Pages에는 ZIP 자체를 올리지 말고 압축을 푼 파일과 폴더를 저장소 루트에 덮어씁니다. 파일명 대소문자를 변경하지 마세요.

기존 v.0.13.a 이상의 전체판을 이미 올려둔 경우, 작은 `v.0.14_GitHub_Update.zip`의 내용물만 저장소에 덮어써도 됩니다. 작은 패치에는 업데이트된 `index.html`, `patch.js`, 초반 적 네 종의 도트, 설명서만 포함됩니다. 나머지 음악·도트는 기존 저장소에 있어야 합니다. 배포 직후 구 버전이 보이면 Ctrl+F5로 강력 새로고침합니다.

WASD 이동 · 커서 방향 자동 평타 · 좌클릭/E 스킬 · Q 궁극기 · 우클릭 대쉬 · Space/C 태그 · Z 진화 · ESC 상태창. 시작 화면과 상태창에서 도움말을 열 수 있습니다.

v.0.14에서 실제 진화 경로에 따른 사용속성 계승, 위자몬·미스티몬 주문 개편, 상점 구매·판매·찜하기 및 진화 단계별 디지에그, 일반 엔딩, 보상 설명과 이동 입력 복구를 반영했습니다. 자세한 내용은 `PATCH_NOTES_v0.14.md`를 확인하세요.
