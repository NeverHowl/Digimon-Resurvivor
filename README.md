## 실행 및 GitHub Pages 업데이트

전체판 ZIP의 **내용물**인 `index.html`, `patch.js`, `mobile_controls.css`, `assets/`를 한 폴더에 풀고 `index.html`을 엽니다. GitHub Pages에는 ZIP 자체를 올리지 말고 압축을 푼 파일과 폴더를 저장소 루트에 덮어씁니다. 파일명 대소문자를 변경하지 마세요.

기존 v.0.13.a 이상의 전체판을 이미 올려둔 경우, 작은 모바일 테스트 업데이트 ZIP의 내용물만 저장소에 덮어써도 됩니다. **`index.html`, `patch.js`, `mobile_controls.css`를 함께** 저장소 루트에 올려야 합니다. 작은 패치에는 초반 적 네 종의 도트와 설명서도 들어 있습니다. 나머지 음악·도트는 기존 저장소에 있어야 합니다. 배포 직후 구 버전이 보이면 강력 새로고침합니다.

시작 화면과 ESC 상태창의 **음량 조절**에서 BGM과 타격 효과음을 각각 0~100%로 조절합니다. 100%가 기존 기본 음량이며 설정은 브라우저에 저장됩니다. 일반 전투·보스·진화 음악에 동일하게 적용됩니다.

이번 테스트판은 속성 스택과 반응의 추가 피해를 속성 투자와 분리해 고정피해로 변경했습니다. 반응 피해는 소모한 두 스택의 총합으로만 기본 배율이 올라갑니다. 자세한 수치는 `PATCH_NOTES_v0.14.md`를 확인하세요.

GitHub 수정본에서는 게임 시작 직후 나타나던 `ReferenceError: keys is not defined`를 해결했습니다. 기존 업데이트를 올렸다면 이 압축의 `index.html`과 `patch.js`를 반드시 함께 덮어쓰세요.

상태창 개편 테스트: ESC 상태창에서 실전 능력치와 보정 배율을 정해진 순서로 표시합니다. 진화 패시브 설명을 한곳에 모으고, 진화 투자에는 점수가 있는 항목만 표시합니다. 피해·충전효율의 `×` 수치는 기본값 대비 보정 배율입니다.

### 모바일 조작 테스트판
휴대폰에서 같은 GitHub Pages 주소로 접속하면 두 레버와 터치 버튼이 표시됩니다. PC에서도 `?mobile=1`을 주소 끝에 붙여 미리 볼 수 있고, `?mobile=0`으로 터치 UI를 숨길 수 있습니다. 게임 시작/체험하기를 누르면 브라우저에 전체화면과 가로 고정을 요청합니다. 지원되지 않는 브라우저에서는 가로로 돌리라는 안내가 나오며, 기기의 화면 회전 잠금을 풀고 직접 돌려야 합니다. 가로 상태에서는 현재 브라우저 화면을 가득 채웁니다. 전체화면·자동 회전은 브라우저/기기 정책에 따라 거부될 수 있습니다.
왼쪽은 이동 레버만 사용하고, 오른쪽 E·Q 버튼 왼편에 태그/대쉬 버튼이 있습니다. 모바일 평타는 사거리 안의 가까운 적을 자동조준합니다. 오른쪽 E/Q 원형 버튼을 누른 채 방향으로 끌어 조준하고 손을 떼면 발동합니다. 해당 방향의 가까운 적을 자동지정해 위치 지정형 스킬과 궁극기도 적을 겨냥합니다. 버튼을 짧게 탭하면 가까운 적을 지정합니다. 오른쪽 아래 서브웨폰 1~3은 즉시 사용합니다. 복싱 모드에서는 E 조준 버튼을 놓으면 왼손 펀치, 대쉬 버튼은 오른손 콤보 입력입니다. 상단에 진화와 상태/도움말 버튼이 있습니다.
GitHub 업데이트 ZIP은 `index.html`, `patch.js`, `mobile_controls.css`를 함께 저장소 루트에 덮어써야 합니다. 이 테스트판은 정식 넘버링을 올리지 않았습니다.

### 동료 위치 및 소규모 밸런스 패치
메인몬이 커서를 따라 오른쪽을 보면 동료들은 왼쪽으로, 왼쪽을 보면 오른쪽으로 걸어서 자리를 바꿉니다. 쥬엘비몬·반쵸스팅몬의 E 연타는 첫 타에만 자연 스택 1개를 부여합니다. 메기드라몬은 상시 피해 감소 25%, 직접 피해 흡혈 50%, 잃은 체력 1%당 공격력 1% 상승(최대 100%)을 얻습니다. E 중 추가 피해 감소는 없고 HP가 1 아래로 떨어지지 않습니다. 지속 E의 남은 시간은 사용 디지몬의 머리 위에, 설치형 기술은 설치 지점에 게이지로 표시합니다.
