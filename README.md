# 디지몬 RE:서바이버 v.0.13.a

`index.html`, `patch.js`, `assets/` 폴더를 **같은 위치**에 두고 웹 서버 또는 GitHub Pages에서 `index.html`을 엽니다. GitHub에 올릴 때 ZIP 자체가 아닌 안의 파일과 폴더를 저장소의 기존 게임 파일 위에 덮어씁니다. 이름의 대소문자를 유지하세요. 배포 후 이전 버전이 보이면 강력 새로고침(Ctrl+F5)을 해주세요.

WASD 이동 · 커서 방향 자동 평타 · 좌클릭/E 스킬 · 우클릭 대쉬 · Q 궁극기 · Space/C 태그 · Z 진화 · ESC 상태 창. 시작 화면의 **게임 시스템 도움말**에서 투자점수, 속성 반응, 그로기를 볼 수 있습니다.

새 계통: 에렉몬·레오몬(반쵸레오몬/샤벨레오몬/화이트레오몬), 베타몬·시드라몬(메가시드라몬/메탈시드라몬), 에어드라몬(메가드라몬/청룡몬). 진화 전 속성 투자점수는 이후 평타·E·Q 피해에 계승됩니다.

이번 ZIP은 전달받은 새 도트와 애니메이션을 기존 게임 리소스에 덮어쓴 **전체 실행판**입니다. 전달받은 ZIP에는 음악이 없으므로 기존 음악 파일을 함께 포함했습니다. 레이어별 랜덤 보스 및 보스 전용 유물은 포함하지 않았습니다.
