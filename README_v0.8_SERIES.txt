[v0.8.1 HOTFIX]
- 레벨업 보상 / 적용 대상 / 디지몬 영입 / 진화 등 모달 선택창에 1초 입력 잠금을 최종 레이어에서 강제 적용.
- v0.8의 함수 재정의 때문에 사라졌던 v0.4.2 입력잠금 래퍼 문제 수정.
- 보상→대상, 대상→뒤로가기, 리롤처럼 같은 모달 안에서 화면이 바뀔 때마다 1초 잠금 재적용.
- pointer/mouse/touch/click 및 Enter/Space 키 입력 모두 잠금 중 차단.

[v0.8.2 HOTFIX]
- 선택창 오입력 방지 시간을 1.0초 → 0.2초로 단축.
- 이전 버전의 700/800/1000ms 잠금 호출도 최종적으로 0.2초를 넘지 않도록 강제 제한.
- 레벨업 보상창이 한 번 열린 뒤 보상→적용 대상→뒤로가기/리롤처럼 같은 창 안에서 이동할 때는 자동으로 잠금을 다시 걸지 않음.
- 연속 큐 모달처럼 예외적인 새 창 진입은 안전을 위해 최대 0.2초 잠금 유지.


[v0.8.3]
- 테이머즈 신규 디지몬 E/Q 직격·범위·지연반응 타격음 보강.
- 테리어몬 계통 투사체 타격음을 공통 스킬 타격음 채널로 통일.
- 임프몬/베르제브몬 폭발은 실제 적중 시에만 타격음 재생.
- 그라우몬/메가로그라우몬 E VFX를 길몬의 3갈래 화염발톱이 확대되어 전방으로 날아가는 형태로 변경. 듀크몬 랜스 VFX는 유지.


[v0.8.4]
- 듀크몬 E 범위를 메가로그라우몬급 이상으로 확대. 좁은 바늘형 랜스 대신 거대한 성창이 전방을 꿰뚫는 VFX로 변경.
- 듀크몬 E 사용 시 일반/퍼펙트 모두 패링 보호막 표시. 퍼펙트 패링 시 보호막과 성창이 더 강하게 강조됨.
- 보호막 접촉 적을 약하게 밀어냄. 보스/엘리트는 밀치기 저항 적용.

[v0.9.0] ELEMENT EXPANSION
- 신규 속성: 바람 / 땅 / 빛 / 어둠.
- 신규 상태: 휘청임 / 진동 / 실명 / 저주.
- 반응 우선순위 고정: 바람+화염 화염폭풍 → 바람+냉기 빙풍 → 땅+바람 모래폭풍 → 빙결+땅 쇄빙 → 전기+땅 접지 → 빛+전기 섬광 → 빛+어둠/어둠+빛 혼돈.
- 반응 피해는 신규 속성스택, 추가 반응, 진동 재전이를 일으키지 않음.
- 신규 속성 강화 카드와 속성별 서브웨폰 8종 추가.
- 파타몬/플롯몬 정규계 Light, 호크몬 Wind, 아르마몬 Earth, 암흑계/임프몬 Dark 중심으로 재분류.
- 크레스가루몬 Physical+Cold, 쉬라몬 계통 기존 속성, 브이드라몬 계통 순수 Physical, 샤크라몬/테리어몬 기존 속성 유지.
- 피요몬은 Fire 스택만 유지하며 E 피해식에 Wind 계수 추가.
- 페가수스몬 계통은 Wind 스택만 부여.
- 엑스브이몬 정규계는 Light 계수 및 실명 E 추가.
- 신규 스킬/서브웨폰/반응에 공통 타격음 처리 및 저비용 Canvas VFX 사용.
