# v0.18.0e · 감염 / 덩굴 지속피해 타격음 개선

- 플로라몬·키위몬·뿌띠몬·케레스몬의 포자 감염 지속피해 타격음을 제거합니다. 전파된 감염 및 궁극기로 강화된 감염도 포함합니다.
- 베지몬·브롯사몬 E 덩굴 장판의 반복 지속피해 타격음을 제거합니다.
- 직격·평타·궁극기 직격과 다른 계통의 타격음은 유지합니다.
- 피해량, 속성 스택·반응, 전염, 속박 및 양분흡수 효과는 변경하지 않습니다.

## 적용

v0.18.0 이상이 적용된 게임 폴더에 patch.js를 덮어쓰세요. 함께 제공하는 index.html도 덮어쓰면 새 버전 주소로 patch.js를 불러옵니다. 특히 v0.18.0c의 별도 실행 파일을 쓰고 있다면 index.html도 반드시 교체하세요.
기존 assets 및 retro_ui.js 등은 유지합니다. 새 리소스는 필요하지 않습니다. 실행 파일명은 patch.js로 유지합니다.
