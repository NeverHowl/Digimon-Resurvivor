# v0.18.21e 일시정지(보상창 등) 중 시간 정지
덮어쓸 파일: index.html, patch.js
- 원인: 기본 update는 paused이면 즉시 반환하지만, 그 위에 겹친 update 래퍼 다수가 paused 확인 전에 쿨다운/지속시간/스킬 효과를 진행(예: 쉴드·궤도 버프, 강화 평타 지속, 태그/가드 무적, 여우 표식 등)
- 수정: 맨 바깥 update 래퍼(G26)에서 일시정지 상태이면 진행 단계를 통째로 건너뜀. 벽시계 기반 효과(장미 강화)는 정지 시간만큼 뒤로 밀림
- 제외: 궁극기 연출 중, 진화 연출, 스테이지 전환, 대화 연출은 기존 동작 유지
- 한계: 스킬 시전 직후 setTimeout으로 예약된 짧은 연타(약 1초 이내)는 일시정지 중에도 이미 예약된 대로 발동
